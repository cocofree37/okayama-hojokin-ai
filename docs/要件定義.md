# 要件定義: おかやま補助金・助成金AI

作成: 2026-11-01 / 発表・公開: 2026-11-01 15:00(岡山市AIブートキャンプ)

## 1. 目的

岡山県内の個人事業主・中小企業が、自分に使える補助金・助成金を見つけて、申請書の下書きまで自力で進められるようにする。
発表で終わらせず、**公開後も地元の事業者に実際に使ってもらう**ことをゴールにする。

### 解決したい課題

- 制度が国・県・市町村に分かれていて、自分に合うものが探せない
- 公募要領が長く、何を書けばよいか分からず申請を諦める
- 商工会・士業などの支援者も、相談1件ごとの制度調べと下書きに時間がかかる

## 2. 利用者

| 利用者 | 使い方 | 求めること |
|---|---|---|
| 事業者本人(主) | 自分で入力し、候補と下書きを得る | 専門用語なしで、少ない入力で結果が出る。スマホでも使える |
| 支援者(商工会・よろず支援拠点・士業・コンサル) | 相談の場で事業者と一緒に入力する | 事業者ごとに入力を切り替えられる。結果を印刷・保存して渡せる |

## 3. 対象範囲

- 地域: **岡山県全域**(国の制度 + 岡山県 + 県内27市町村)
- 制度: 補助金、助成金(融資は候補に出してよいが主対象外)
- 補助金・助成金だけを扱う単独のアプリにする(マニュアル化AI・セキュリティ診断とは統合しない)

### やらないこと

- 申請の代行、電子申請の操作、採択・受給の保証や可否の断定
- 税務・法律の判断(必要な点は「専門家・窓口に確認」と案内する)
- 事業者の情報をサーバーに保存すること(入力は利用者の端末のみに保存)

## 4. 機能要件

優先度: **MUST** = 15時までに必要 / **SHOULD** = 公開後1ヶ月以内 / **COULD** = 将来

### 4.1 事業者プロフィール

| ID | 要件 | 優先度 |
|---|---|---|
| P-1 | 業種、事業形態、所在地、従業員数、事業内容、やりたいこと、予定金額、時期を入力できる | MUST |
| P-2 | 事業内容かやりたいことのどちらかがあれば検索できる(他は空欄可) | MUST |
| P-3 | 入力は端末に保存され、次回も残る | MUST |
| P-4 | 「入力をクリア」で次の事業者の入力に切り替えられる(支援者向け) | MUST |
| P-5 | 事業者を複数保存して切り替えられる(支援者向け) | SHOULD |
| P-6 | 入力例・記入のコツを各項目に表示する | MUST |

### 4.2 制度の候補

| ID | 要件 | 優先度 |
|---|---|---|
| S-1 | 国・県・市町村の公式サイトを検索し、合う制度を3〜6件表示する | MUST |
| S-2 | 各候補に、制度名・実施主体・種別・概要・合う理由・金額/補助率・公募期間・状況・注意点を表示する | MUST |
| S-3 | 公式ページへのリンクは、実際の検索結果に出たURLだけを表示する | MUST |
| S-4 | 検索対象を県内27市町村の公式サイトまで広げる | MUST |
| S-5 | 調べた日を表示する | MUST |
| S-6 | 候補一覧を印刷・保存できる | SHOULD |
| S-7 | 所在地の市町村の制度を必ず1回は検索する | MUST |

### 4.3 申請書の下書き

| ID | 要件 | 優先度 |
|---|---|---|
| D-1 | 選んだ制度の公募要領・審査項目を調べ、それに沿った見出しで下書きを作る | MUST |
| D-2 | 入力にない事実は【要記入: ○○】で残し、創作しない | MUST |
| D-3 | 足りない情報の一覧を出し、入力して作り直せる | MUST |
| D-4 | 提出前のチェックリスト、参照した公式ページを表示する | MUST |
| D-5 | コピー、テキスト保存ができる | MUST |
| D-6 | Word形式で保存できる | COULD |

### 4.4 案内・運用

| ID | 要件 | 優先度 |
|---|---|---|
| G-1 | 「制度は変わる・公募要領で確認」「下書き支援で代行ではない」「入力はAIに送信される」を画面に明示する | MUST |
| G-2 | 相談窓口(よろず支援拠点、商工会議所・商工会)を案内する | MUST |
| G-3 | 感想・不具合の問い合わせフォームを置き、support@cocofree.jp に届ける(全ページのメニューから開ける。返信先メールは任意) | MUST |
| G-4 | 利用件数を把握できる(個人を特定しない集計のみ) | SHOULD |

## 5. 非機能要件

| 項目 | 要件 |
|---|---|
| 正確さ | 検索は公式サイトに限定。金額・締切は検索で確認できたものだけ表示し、不明なら「公募要領で確認」と出す |
| 応答時間 | 候補は2分以内、下書きは3分以内を目安。待ち時間中は進行中であることを表示する |
| 費用 | 1回数十円程度。同一IPは1分3回まで。Anthropic側で月の利用上限を設定する |
| セキュリティ | APIキーはサーバー(Worker)だけに置く。AIへの入力は資料として扱い、入力中の指示には従わない |
| 個人情報 | サーバーに保存しない。個人名・口座番号などは入力しないよう案内する |
| 使いやすさ | スマホ幅で崩れない。本文16px以上。専門用語は避ける |
| 安定性 | AIが使えないときは、エラー内容と再試行の案内を表示する |

## 6. 成功の指標

- 発表: 実際の入力から候補→下書きまで、会場で通しで見せられる
- 公開後1ヶ月: 利用件数、下書きまで進んだ割合、支援者1団体以上からの感想
